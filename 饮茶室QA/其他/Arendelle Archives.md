# Arendelle Archives

资料性介绍，不是 Frozen 文本理论。Snowflake 在群里应 JU 之请说明这个英文圈档案组做过什么、和饮茶室如何重叠。

> *2025-08-17 03:36:26  Snowflake*
这里简单介绍一下 Arendelle Archives。这是一个由热爱世界观与设定的冰粉组成的团队，以 Tumblr 为发布平台，Discord （非公开）为主要交流基地。

最初是在2022年，由两位大佬 Saiten 和 FH 的编年史项目起步，后来遇到了对阿伦戴尔实际地理进行深入分析的 Winter，三人于是组成团队。此后，越来越多热爱冰学的成员陆续加入。（如果有说得不对的地方，还请 FrozenHeart 帮忙指正，因为我是2024年1月才加入的，可能了解得不够全面。）

目前已经完成的主要项目有：

- 编年史（2022年）
- 所有书籍短片播客等的整合列表（2022年）
- 阿伦戴尔的实际地理位置分析（2023年）
- 阿伦戴尔皇室族谱（2024年）
- 所有出现在电影和书籍中的角色合集（2025年）

Tumblr 已完成项目列表：<https://www.tumblr.com/arendelle-archives/788818181610520576/arendelle-archives-project-list-july-2025?source=share>

Discord server 入群条件较严（知道 Archives 是干什么的、对冰学感兴趣并愿意贡献），管理层对 Discord 不熟，Welcome 频道当时还缺。
